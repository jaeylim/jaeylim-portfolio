### 컴플라이언스 대응 프로세스

#### PCI-DSS 증적 수집

다음 항목을 직접 점검·캡처하여 증적으로 관리:

- Security Group 최소 권한 여부
- IAM Password Policy 설정값
- IAM Policy JSON 내 Action/Resource 범위
- Network Firewall Logging 및 CloudWatch Alarm 설정
- GuardDuty → EventBridge → SNS 알림 흐름 동작 확인

#### ISO 27001:2022 갱신 심사 대응

내부 보안팀과 협업하여 갱신 심사 증적 자료를 준비하고 감사에 대응. 2013판 → 2022판 개정에 따른 통제 항목 변경 사항을 매핑.

#### CSAP 보안인증 사후평가

연 1회 진행되는 CSAP 사후평가(서면평가 체계) 대응을 위해 증적자료 수집을 담당. SaaS 표준형 인증 서비스의 별첨3 등 제출 자료를 준비하고, 관련 팀원(개발/운영 담당자)과 증적 수집 범위를 조율.

#### 개인정보보호법 개정 대응

2026년 개인정보보호법 개정사항(CPO 지정, 유출 통지, 과징금 등)을 반영하여 내부 개인정보보호정책 문서를 갱신하고, ISO 27001:2022 통제 항목과의 매핑 작업을 수행.
